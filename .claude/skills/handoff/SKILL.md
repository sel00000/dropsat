# 세션 마무리 (핸드오프)

AGENTS.md의 "세션 끝날 때" 절차를 실행한다.

1. 내 역할을 확인한다: `team/me.local.md` 또는 사용자에게 질문.
2. 이번 세션에서 바뀐 것을 파악한다: `git status`, `git diff`, 이번 세션의 커밋.
3. `team/STATUS.md`의 **내 역할 섹션만** 고친다. 다른 섹션은 건드리지 않는다 (예외: 내가 처리한 요청 줄 끝에 ✅ 붙이기).
   - 업데이트: 현재 시각 (KST, `YYYY-MM-DD HH:MM`)
   - 한 일: 이번 세션 결과. 파일 경로를 넣어 3줄 이내
   - 다음: 다음 세션에서 할 일
   - 막힘: 없으면 "없음"
   - 요청: 다른 파트에 필요한 것 `→역할: 내용`
4. 남에게 영향을 주는 결정을 했으면 `team/DECISIONS.md` 맨 아래에 새 항목을 추가한다 (형식은 파일 상단).
5. 데이터 형식을 바꿨으면 `team/DATA_CONTRACT.md`의 버전과 변경 이력을, 새 용어가 생겼으면 `team/GLOSSARY.md`를 갱신한다.
6. 바뀐 파일 목록과 커밋 메시지(`[역할] 요약`)를 보여 주고, 사용자가 확인하면 커밋하고 push 한다.
7. 다음 사람이 알아야 할 것을 3줄 이내로 보고한다.

# 용어집 (GLOSSARY)

> 화면 문구·발표 자료·코드 주석에서 **같은 것을 같은 이름으로** 부르기 위한 표다.
> 에이전트는 화면 문구를 쓸 때 '화면 표기'를 따르고, 여기에 없는 용어를 새로 만들면 표에 추가한다.
> 추가는 누구나. 기존 항목의 뜻(정확성)은 data, 표기(말투)는 ux가 최종 확인한다.

## 표기 규칙

- 시간: `T+01:27:49` (사출 후 경과). 날짜가 필요하면 "2026-10-10 (시뮬레이션 가정)".
- 단위: 우선 `out/mission_log.txt` 표기를 따른다. 예: `8.18 V`, `92%`, `16°C`, `0.27°/s`, `600 km`. 바꾸려면 ux가 여기서 고친다.
- 시뮬레이션 데이터를 보여 주는 화면에는 "시뮬레이션"이라고 밝힌다 (실제 비행 데이터가 아니다).
- 그래프 색: 기존 그래프(`tools/plot.py` 상단)에 팔레트가 있다. 웹에서도 쓸지는 ux가 정한다.

## 운용 모드

출처: `fsw/proto.h`, 화면 표기는 `tools/plot.py`의 `MODE_NAME`과 같다.

| 코드 | 화면 표기 | 설명 |
| --- | --- | --- |
| 0 `DEPLOY_WAIT` | 전개 대기 | 사출 직후. 30분 뒤부터 안테나 전개를 시도한다 |
| 1 `DETUMBLE` | 디텀블링 | 사출 직후의 회전(텀블링)을 멈추는 단계 |
| 2 `NOMINAL` | 정상 운용 | 비콘 송신, 명령 수신, 실험 수행 |
| 3 `SAFE` | SAFE | 전력 부족이나 이상이 생기면 최소 기능만 남기고 버티는 모드 |

## 위성·임무

| 용어 | 화면 표기 | 쉬운 설명 |
| --- | --- | --- |
| CubeSat, 2U | 큐브샛 (2U) | 한 변 10 cm 정육면체(1U) 두 개 크기의 초소형 위성. DROPSAT-1은 2.2 kg |
| 사출 | 사출 | 위성이 발사체에서 떨어져 나오는 순간. 시간 기준점 T+0 |
| MET | 위성 시계 | Mission Elapsed Time. 위성이 스스로 세는 경과 시간 |
| 태양동기궤도 (SSO) | 태양동기궤도 | 매일 같은 지방시에 같은 위도 위를 지나는 궤도. DROPSAT-1은 고도 600 km |
| eclipse | 지구 그림자 | 위성이 지구 그림자에 들어가 태양전지가 발전하지 못하는 구간 |
| OBC | 탑재 컴퓨터 (OBC) | 위성의 두뇌 역할을 하는 컴퓨터 |
| FSW | 비행 소프트웨어 | OBC에서 도는 프로그램 (`fsw/`) |
| HAL | 하드웨어 추상화 계층 | 비행 SW와 하드웨어 사이의 경계. 시뮬레이터가 실제 하드웨어 대신 이 자리에 들어간다 |
| SEU | 우주방사선 단일사건 (SEU) | 방사선 입자 하나가 메모리 비트를 뒤집는 현상. 시나리오에서 T+8h에 OBC가 멈춘다 |
| 워치독 | 워치독 | 프로그램이 멈추면(시뮬레이터에서는 2초) 컴퓨터를 자동으로 재시작하는 안전장치 |
| CubeSat 규격 | CubeSat 설계 규격 | 사출 30분 전 전개 금지, 45분 전 송신 금지 (CubeSat Design Specification Rev 14.1) |

## 자세제어 (ADCS)

| 용어 | 화면 표기 | 쉬운 설명 |
| --- | --- | --- |
| ADCS | 자세제어계 | 위성의 방향과 회전을 다루는 장치와 소프트웨어 |
| 텀블링 | 텀블링 | 위성이 제멋대로 도는 상태. 시나리오에서 사출 직후 약 11°/s |
| 디텀블링 | 디텀블링 | 회전을 1°/s 아래로 줄여 5분 동안 유지하면 완료 |
| B-dot | B-dot 제어 | 지구 자기장이 변하는 빠르기를 보고 회전을 줄이는 제어 방법 |
| 자력계 | 자력계 | 지구 자기장을 재는 센서 |
| 자기토커 (MTQ) | 자기토커 | 전류로 자석을 만들어 지구 자기장과 밀고 당기며 회전을 줄이는 장치 |

## 전력 (EPS)

| 용어 | 화면 표기 | 쉬운 설명 |
| --- | --- | --- |
| EPS | 전력계 | 태양전지, 배터리, 전원 분배 |
| SoC | 배터리 잔량 | State of Charge. 0~100% |
| 2S1P 18650 | 18650 배터리 2개 직렬 | 리튬이온 18650 셀 두 개를 직렬로 연결 |
| 배터리 히터 | 배터리 히터 | 배터리가 2°C 아래로 식으면 켜고 6°C가 되면 끈다 |
| 저온 충전 금지 | 저온 충전 금지 | 0°C 이하에서 충전하면 배터리가 상하므로 충전을 막는다 |
| SAFE 진입 조건 | | 배터리 잔량 20% 미만, 전압 6.6 V 미만, 10분 안에 3번 연속 리셋 중 하나 |

## 통신·보안

| 용어 | 화면 표기 | 쉬운 설명 |
| --- | --- | --- |
| 지상국 | 대전 지상국 | 위성과 교신하는 지상 안테나. UHF 437 MHz |
| 교신 (pass) | 교신 | 위성이 지상국 하늘을 지나가며 통신할 수 있는 몇 분 |
| AOS / LOS | 교신 시작 / 교신 끝 | 위성이 지평선 위로 떠오름 / 넘어감 |
| 고도각 | 고도각 | 지상국에서 올려다본 위성의 높이 각도. 5° 이상이면 교신 |
| 비콘 | 비콘 | 위성이 자기 상태를 주기적으로 방송하는 신호. 정상 30초, SAFE 120초마다 |
| 텔레메트리 | 상태 데이터 | 위성이 지상으로 보내는 측정값 |
| 명령 (업링크) | 명령 | 지상에서 위성으로 보내는 지시 (PING, SET_TIME, EXP_SCHEDULE 등) |
| CRC | 오류 검사 | 통신 중 깨진 프레임을 걸러내는 검사값 |
| MAC (SipHash) | 명령 인증 | 비밀키로 만든 서명. 키가 없는 사람이 만든 위조 명령을 버린다 |
| 재전송 공격 (replay) | 재전송 공격 | 예전 명령을 녹음했다가 다시 보내는 공격. 받은 명령 번호(seq)가 마지막으로 실행한 번호보다 크지 않으면 버린다 |
| seq | 명령 번호 | 명령마다 1씩 커지는 번호 |

## EWOD 탑재체

| 용어 | 화면 표기 | 쉬운 설명 |
| --- | --- | --- |
| EWOD | EWOD 액적 실험 | Electrowetting-on-Dielectric. 전극에 전압을 걸어 작은 물방울(액적)을 원하는 곳으로 옮기는 기술 |
| 액적 | 액적 | 칩 위의 작은 물방울 |
| 전극 | 전극 | E0는 저장조, E1~E8은 액적이 지나가는 트랙 |
| 디스펜스 | 액적 떼어내기 | 저장조에서 액적 하나를 떼어내는 단계 |
| AC / DC 구동 | 교류 구동 / 직류 구동 | 시나리오에서 실험 #1은 AC 110 V, #2는 DC 110 V |
| 왕복 | 왕복 | 액적이 트랙을 한 번 갔다가 돌아오는 것 |
| 누설전류 | 누설전류 | 절연막을 새어 나가는 전류. 커지면 절연막이 망가지는 신호 |
| 포획전하 (`v_trap`) | 포획전하 | 절연막에 갇힌 전하가 실제로 걸리는 전압을 깎는 현상. 시뮬레이터 모델에서는 DC 구동에서 빨리 쌓이고 AC에서는 거의 안 쌓인다 (쌓이는 속도는 실험으로 정해야 할 **가정값**) |
| STUCK | 액적 멈춤 | 액적이 다음 칸으로 움직이지 못해 실험이 멈춘 결과 |
